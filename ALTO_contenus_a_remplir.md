# ALTO - Contenus du site a completer

Document de travail pour recueillir les textes definitifs du site ALTO.

Le site que vous avez vu est une maquette de presentation. Les textes qui y figurent ne sont que des exemples destines a montrer la mise en page. Ils seront remplaces par les vos.

## Comment remplir ce document

1. Sous chaque element, ecrivez votre texte a la ligne "Votre texte".
2. Si le texte d'exemple vous convient tel quel, ecrivez simplement "OK a garder".
3. Merci de respecter au mieux les longueurs conseillees : elles garantissent que le texte reste lisible dans la mise en page (titres, boutons et cartes ont un espace limite).
4. Pour les listes (evenements, partenaires), copiez le bloc autant de fois que necessaire.
5. Toute remarque, variante ou question est la bienvenue : ecrivez-la a la suite de l'element concerne.

Rappel de positionnement (issu du cahier des charges), a garder en tete pour le ton des textes :
- Concept central : le renouveau.
- Style : minimaliste, editorial, premium, sobre.
- Ne pas mentionner la ville ni la localisation dans les textes.
